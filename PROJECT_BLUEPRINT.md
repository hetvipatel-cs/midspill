#Classes and Objects
-A Book has a title, author, genre, rating, and reading status.
-A Character has a name, personality, background, and relationships.
-A Story has a title, description, and characters.
-A Chapter belongs to a story.

-*Identify the attributes of each object:*
-Book objects should have a title, genre, author, pages, rating, and reading status
-Journal objects should have a title and type
-Character objects should have a name, age, gender, personality, background, and relationships
-Story objects should have a title, description, characters, ending type, and completion status
-Chapter objects should have a title, chapter type, word count, and completion status
-Identify which objects need to reference other objects:
-Stories should have characters and chapters
